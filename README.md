# «Система ясности»: подготовка переноса с Тильды

Архив на текущем тарифе не скачивается, поэтому источник собирается с опубликованного сайта.

Обновить снимок. Повторный запуск в тот же день докачивает недостающее, параметр `--force-pages` заново берёт HTML:

```bash
python3 -I tools/capture_site.py
```

Снять эталоны с живого сайта (скрины 1440 и 390, высоты блоков, адреса, которые запрашивает браузер):

```bash
python3 tools/verify_snapshot.py reference
```

Проверить снимок без сети и сравнить с эталоном. Код выхода 1 означает, что чего-то не хватает:

```bash
python3 tools/verify_snapshot.py local
```

Порядок для нового снимка: `capture_site`, `reference`, снова `capture_site` (докачает адреса из браузера), `local`.

Что лежит в `sources/live/<дата>/`: `pages/` — исходный HTML, `assets/` — файлы, `t123/` — встроенный код блоков, `reference/` — эталонные скрины и замеры, `manifest.json`, `inventory.json`.

## Локальная сборка и проверка

Из корня проекта:

```bash
npm run normalize && npm run build:site
npm test
npm run smoke
npm run smoke -- firefox
npm run smoke -- webkit
python3 tools/check_autoscale.py local
```

Сборка `dist/` использует сохранённый снимок, по умолчанию закрыта от индексации. Для просмотра — `npm run preview` и `http://127.0.0.1:4186/`. Нормализация использует Beautiful Soup, для оптимизации PNG и сравнений нужны Pillow с WebP и Python Playwright. FFmpeg создаёт заставки и MP4 с быстрым стартом без перекодирования. Для воспроизведения проверенной сборки и видео-сценариев нужны эти зависимости. Смоук берёт Node Playwright из локального `kinezio-hw-qa`.

Смоук запускает свой loopback-сервер. Chromium проверяет все 12 страниц на 1440 и 390 и расширенные сценарии. Firefox проверяет десктоп, WebKit — десктоп и эмуляцию телефона. Kommo и Метрика проверяются с локальными заглушками в Chromium. Для сравнения автоскейла на 320, 360, 412 и 480 используются сохранённые эталоны. Отчёты находятся в `docs/smoke*.json` и `docs/screens/autoscale/measures.json`.
