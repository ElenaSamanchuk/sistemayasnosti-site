# Ежемесячное обновление аудиоклуба — порядок (Claude, 09.11.2026)

Основано только на коде и README проекта `~/Projects/sistema-yasnosti-club` (прошлые отчёты и живую Тильду не сверял). Сборка делает три блока HTML-код (T123) для страницы Тильды; новый сайт `sistemayasnosti-site` ссылается на текущую сборку.

## Что откуда берётся

| Что | Где | Как меняется |
| --- | --- | --- |
| Каркас страницы (Vue/Tailwind одним html) | `source/audioclub-*.html`, берётся последний по имени | только когда разработчик пришлёт новую сборку |
| Тексты месяца: тема, подводка, 12 выпусков, заголовки, FAQ, цены, кнопка оплаты | `scripts/audioclub-content.mjs` (функция `getAudioclubContentBlock`, подставляется вместо блока `zt…dH` в JS) | правится каждый месяц вручную по ТЗ |
| Кнопки «Послушать в боте» на выпусках 01–02, ссылка | тот же файл: `BOT_EPISODES` (`?start=audio_nov`), флаг `SHOW_BOT_EPISODES` | ссылку менять на месяц, флаг включать после проверки аудио |
| Обложка месяца | `source/img/hero-player.png` (роль `hero-player`; также `vinyl-mark`, `author-1…3`, `faq-photo-1…2`) | заменить файл, сборка сожмёт в WebP |
| Ссылка оплаты Tribute и музыка | флаги `--bot` и `--music` в `npm run build` (`package.json`) | обычно не меняются |
| Оформление, плеер, скролл | `scripts/build-tilda.mjs`, `scripts/runtime.js` | не трогать без причины; при смене структуры присланной сборки скрипт падает с понятной ошибкой |

## Порядок

1. Положить ТЗ и обложку в `source/<месяц>-2026/`, обложку скопировать в `source/img/hero-player.png`.
2. Обновить `scripts/audioclub-content.mjs`: тема, даты и названия 12 выпусков, подводки, `BOT_EPISODES`.
3. `cd ~/Projects/sistema-yasnosti-club && npm i` (один раз) и `npm run build`. В выводе смотреть предупреждения: плейсхолдер бота, «файлов ещё нет в origin/main».
4. Обновить ожидания в `tools/adaptive.mjs` (строка `checks`: тема, заголовок «12 выпусков …», финальный призыв, ссылки `audio_*`, отсутствие прошлого месяца). Они зашиты на ноябрь, без правки проверка сразу покраснеет.
5. Проверка без ИИ: `python3 -m http.server 5568 --bind 127.0.0.1`, затем `node tools/adaptive.mjs` (11 размеров × Chromium/WebKit/Firefox, нужен Playwright из `kinezio-hw-qa`; логи в `docs/devtools/`, снимки в `docs/screens/`) и `node tools/hero-alignment.mjs` (выравнивание первого экрана). Ждать все `checks=true`, HTTP 200, 0 ошибок JS и битых картинок.
6. Коммит и push в `main` до вставки в Тильду, иначе картинки с jsDelivr дадут 404 (кеш 404 сбрасывается запросом purge из README). Предпросмотр: GitHub Pages `https://elenasamanchuk.github.io/sistema-yasnosti-club/`.
7. В Тильде заменить целиком блоки `tilda/1-css.html` и `tilda/3-js.html` (`2-html.html` меняется редко, сверить `git status`) или один блок `tilda/external.html`; опубликовать. Имена файлов содержат хеш, поэтому вставлять заново после каждой пересборки.

## Что проверить перед выкладкой

- Тема и 12 названий совпадают с ТЗ; цена 35 € новым и 29 € действующим, FAQ, плашка зачёта в курс не потеряны.
- Обе кнопки бота ведут на актуальную ссылку месяца; оплата остаётся на Tribute `s18xT`.
- Старой темы и старого `audio_*` в тексте нет; в тексте нет слов про «бесплатно».
- Обложка новая, не прошлого месяца (`alt` и название файла в `assets/img`).
- Не проверяется скриптами: выдача выпусков ботом, оплата и автопродление, физические телефоны, меню/футер/SEO на самой Тильде. Это делается отдельно.
- Чужие неотслеживаемые файлы (`assets/tilda`, `docs`, `debug-premin.js`) в коммит не включать автоматически.
