## 1. Вывод

Переиспользовать можно, и существенно. Главная находка: у Медведевой уже есть второй путь входа. `normalize_export.py::compile_page` читает опубликованный HTML из `sources/current-page-sources.json` (путь, `sha256`, дата снимка) вместо файла архива. Структура записей в опубликованном HTML та же, что у нас: `[data-record-type]`, `.t396__artboard`, `data-elem-id`, `data-field-*-res-N-value`, `data-group-id`, `style` внутри записи с селекторами `#recNNN .tn-elem[data-elem-id=…]`. Проверено на `pages/oferta.html` и `pages/index.html` нашего снимка: атрибуты `data-elem-type='…'` (в одинарных кавычках), `data-artboard-screens="320,480,640,960,1200"`, `data-animate-*` присутствуют. Значит ядро (Zero в сцены + CSS) переносится почти без изменений. Переделывать нужно вход (манифест, медиа), всё привязанное к Медведевой и обработку типов, которых у неё нет (меню T228, T123, видео-элемент, индикатор T602).

## 6. Риски и оговорки

1. Запись `rec2194603223` (`data-popup-rec-ids` для `#zeropopupmain` на главной) в HTML снимка есть только как CSS-селекторы, самого `<div id="rec2194603223">` нет, а `.t-popup__container` пуст. Остальные четыре попапа имеют записи на странице. Нужно проверить снимок и при необходимости снять запись заново (read-only); иначе содержимое попапа будет утеряно.
2. Скрытые страницы (`/pred`, `/pred_fl`) из публичного HTML недоступны (404). Если их захотят публиковать, потребуется другой источник.
3. Анимации `sbs` `scroll` (13) и `blockintoview` (2), `data-elem-type='video'` (4) в сборщике Медведевой не покрыты. Без них главная и `/clarity` могут отличаться от живой.
4. Весь опубликованный HTML содержит скрипты Тильды и инлайн-код. По правилам проекта его не запускать и не включать в сборку: сборщик Медведевой это соблюдает (`clean_html` вырезает `script/style/iframe/form/input`, `on*` и `data-*`). Сохранить это.
5. `localize()` и сопоставление картинок построены под «UUID__имя» из архива; у нас по URL и хэшу. Ошибка в сопоставлении проявляется как битые картинки: smoke `routes-smoke.mjs` проверяет `broken`, использовать на каждом шаге.
6. Совпадение id (cookie-кнопка `1773213623325000005`) показывает общий шаблон Тильды у двух проектов, но остальные id нужно сверять заново. Не переносить id из `App.vue` Медведевой без проверки.
7. `/about` содержит продублированные служебные блоки: нужна дедупликация по `rec`-id при сборке страниц.
8. Юр-страницы смесь русского и испанского (`Aviso Legal`, `Términos`): типограф Медведевой знает только русские короткие слова; текст не менять, неразрывные пробелы расставлять осторожно.
9. Смоук-скрипты импортируют Playwright из `~/Projects/kinezio-hw-qa/node_modules`. Для нашего проекта лучше указать общий путь или установить локально (это отдельное решение; установка пакетов ничего платного не включает, но выходит за рамки этого плана без согласования).
10. Оценки часов приведены в диапазонах и не проверены на нашем коде; уточнить после шага 4.
