# Выкладка и страницы продаж

Секретов здесь нет. Адрес общей VM и пути на ней указаны только в `ADMIN-PREVIEW.md`. Выкладка, DNS и сертификаты выполняются только по отдельному поручению.

При боевом выпуске настроить 301 с `www.sistemayasnosti.com` на `sistemayasnosti.com`: Метрика и Kommo работают только на адресе без www.

## Два варианта превью

- [GitHub Pages](https://elenasamanchuk.github.io/sistemayasnosti-site/) использует `SITE_BASE=/sistemayasnosti-site/`. Репозиторий Pages содержит собранную статику, источник сборки `main:/`.
- [Архив для VM](https://github.com/ElenaSamanchuk/sistemayasnosti-site/releases/tag/vm-preview-20261110-8) собран от корня `/`. Скачать именованный `.tar.gz` и файл `.sha256` из Assets. Порядок установки и проверки соседних сайтов в [инструкции админа](ADMIN-PREVIEW.md).

## Режимы сборки

- По умолчанию (превью): на всех страницах `noindex,nofollow`, в `robots.txt` запрет всего сайта.
- Архивы `vm-preview-*` собраны как превью и закрыты от индексации. Для боевого выпуска собрать заново с `SITE_ENV=production`.
- `SITE_ENV=production`: индексация разрешена, в `robots.txt` указан `sitemap.xml`. Секретные ссылки продаж и страница 404 остаются закрытыми от индексации.

Для MP4 и MP3 статический сервер должен обслуживать одиночные диапазоны `Range: bytes=…` с ответом `206`. Это нужно для загрузки медиа в Safari/WebKit. Локальное превью поддерживает этот режим.

```bash
SITE_ENV=production npm run build:site     # боевая сборка
npm run build:site                         # превью
```

## Закрыть и открыть продажи (`/pred`, `/pred_fl`)

Один файл: `sources/sales-pages.json`. Для каждого адреса поле `open`.

Закрыть продажи: `"open": false`, в `redirectTo` указать, куда вести (сейчас `/clarity`, это предложение, Еленой не подтверждено). Пересобрать сайт. Адрес станет временным перенаправлением (302) с сохранением query-строки (UTM, `r` и т. д.).

Открыть продажи: `"open": true`, пересобрать, выложить `dist/`. Страница откроется на своём адресе.

После сборки при закрытых продажах:
- `dist/pred/index.html` и `dist/pred_fl/index.html` — страницы-перенаправления (`noindex`);
- `deploy/nginx-sales-redirects.conf` — правила `return 302` для nginx. Подключить внутри `server { … }` и перезагрузить nginx (`nginx -t`, затем `reload`). Если правило не подключено, работает страница-перенаправление; при открытии продаж файл станет пустым комментарием, а подключённую строку `include` оставлять можно;
- адреса продаж в `sitemap.xml` не попадают.

Проверка закрытой страницы до открытия: задать токен только в окружении сборки (12+ символов: буквы, цифры, `-`, `_`; в файлы он не записывается):

```bash
SALES_PREVIEW_TOKEN='<свой токен>' npm run build:site
```

Настоящая страница будет по адресу `/pred-preview-<токен>/` и `/pred_fl-preview-<токен>/` (`noindex`). Токен передавать только тем, кто проверяет. Сменить токен: поменять значение и пересобрать, старая ссылка перестанет существовать после выкладки. Без токена секретной ссылки нет.

Если исходника страницы ещё нет, сборка не падает: делает перенаправление и пишет предупреждение «страницы продаж».
